แผนการดำเนินงานวิจัยและพัฒนาระบบ LoRa Mesh (5-Phase Engineering Roadmap)

================================================================================
ตารางสรุปภาพรวมแผนการดำเนินงาน 5 ระยะ (Summary Roadmap)
================================================================================
Phase 1: ข้อกำหนดและการเลือกแนวทาง (สัปดาห์ที่ 1–2)
- เป้าหมาย: เลือกสถาปัตยกรรมโปรโตคอลให้ตรงกับโจทย์
- กิจกรรม:
  * กำหนดขนาด Payload และความถี่ในการส่ง (เช่น 10–50 Bytes ทุก 5–15 นาที)
  * เลือกสถาปัตยกรรม: AlLoRa (คัสตอม/ส่งไฟล์), LIMA (เสริม LoRaWAN เดิม), Meshtastic (P2P ไร้เน็ต), หรือ TDMA (ปลอดการชน)
  * กำหนดย่านความถี่ กสทช. AS923 (920–925 MHz)
- ผลลัพธ์ (Deliverables): เอกสาร System Architecture & Protocol Specification

Phase 2: จัดเตรียมฮาร์ดแวร์ & พัฒนา Firmware ขั้นต้น (สัปดาห์ที่ 3–4)
- เป้าหมาย: เชื่อมต่อวงจรและทดสอบรับส่ง Point-to-Point
- กิจกรรม:
  * ประกอบบอร์ด ESP32 เข้ากับโมดูล SX1262/SX1276 ผ่าน SPI
  * เชื่อมต่อเซนเซอร์วัดค่าสภาพแวดล้อม/ดิน/การเกษตร และวงจรโซลาร์เซลล์
  * พัฒนาเฟิร์มแวร์สื่อสารพื้นฐาน (P2P) ด้วย RadioLib วัดค่า RSSI, SNR, Packet Loss, และ Time on Air
- ผลลัพธ์ (Deliverables): ต้นแบบ Node และ Gateway อย่างละ 1 ชุด ที่สื่อสารทางตรงได้

Phase 3: พัฒนาและทดสอบลอจิก Mesh & Routing (สัปดาห์ที่ 5–8)
- เป้าหมาย: สร้างกลไกการส่งต่อข้อมูลแบบหลายช่วง (Multi-hop)
- กิจกรรม:
  * เขียนลอจิก Forwarding และกำหนดโครงสร้าง Header (SrcID, DestID, TTL, SeqNo)
  * ใส่ระบบ Duplicate Detection (จำ ID ล่าสุด) ป้องกันลูปและ Broadcast Storm
  * พัฒนาระบบยืนยันข้อมูล (ARQ) หรือจูนค่า SF อัตโนมัติ (ADR)
  * จัดการวงจรประหยัดพลังงาน (Deep Sleep) ของโหนดเซ็นเซอร์
- ผลลัพธ์ (Deliverables): เฟิร์มแวร์ Mesh Protocol ที่รองรับ Multi-hop อย่างน้อย 2–3 Hops

Phase 4: การรวมระบบและส่วนติดต่อผู้ใช้ (Integration) (สัปดาห์ที่ 9–10)
- เป้าหมาย: เชื่อมต่อ Gateway เข้ากับระบบจัดการข้อมูล
- กิจกรรม:
  * พัฒนา Gateway ส่งข้อมูลออกสู่ Cloud ผ่าน Wi-Fi/4G ด้วย MQTT หรือ HTTP
  * ติดตั้ง MQTT Broker (Mosquitto/EMQX) และ Database (InfluxDB/PostgreSQL)
  * สร้างหน้า Dashboard (Grafana/Node-RED) แสดงค่าเซนเซอร์, สถานะโหนด, และเส้นทาง Routing Topology
- ผลลัพธ์ (Deliverables): ระบบปลายทาง (End-to-End System) แสดงผลข้อมูลได้แบบเรียลไทม์

Phase 5: ทดสอบในสภาพแวดล้อมจริงและปรับจูน (สัปดาห์ที่ 11–14)
- เป้าหมาย: วัดประสิทธิภาพและแก้ไขจุดอับสัญญาณ
- กิจกรรม:
  * นำอุปกรณ์ไปติดตั้งทดสอบในพื้นที่จริง (LOS โล่งแจ้ง vs. NLOS ป่า/แปลงเกษตร/อาคารบัง)
  * เก็บสถิติ Packet Delivery Ratio (PDR > 90%), End-to-End Latency (< 5s), และอัตรากินพลังงาน (mAh)
  * ปรับตำแหน่ง Relay Node และจูนค่า SF/BW เพื่อขจัดจุดอับสัญญาณ
- ผลลัพธ์ (Deliverables): รายงานสรุปผลการทดสอบประสิทธิภาพเครือข่ายจริง (Performance Report)

================================================================================
ฮาร์ดแวร์และเครื่องมือที่แนะนำ (Recommended Toolset)
================================================================================
- Development Board: LilyGO TTGO T-Beam (ESP32 + SX1262 + GPS + วงจรชาร์จ 18650)
- Low-Power Node: RAKwireless WisBlock (nRF52840 + SX1262) กินไฟต่ำระดับไมโครแอมป์
- LoRa Library: RadioLib ยืดหยุ่นสูงสุดในการควบคุม Register ของ LoRa
- Network Simulator: ns-3 (โมดูล ns3-lorawan) ใช้จำลองสเกล 50-100 โหนด
- Dashboard: Grafana + InfluxDB แสดงผลกราฟ Time-series และแผนที่ Real-time
