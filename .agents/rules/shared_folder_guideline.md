# Shared Folder Rule for Project Co-op

## สำคัญยิ่งยวด (Strict Requirement)
- ทุกไฟล์งานวิจัย, เอกสารสรุปเนื้อหา (Study Guides), ตาราง Kanban, บันทึกการทดลอง, และเอกสารที่ต้องแชร์กับเพื่อน (Yo) **จะต้องสร้างและอัปเดตภายใต้ไดเรกทอรี [`share_friend/`](file:///d:/ProjectCo-op/share_friend/) เท่านั้น**
- ไดเรกทอรี `share_friend/` คือ **Obsidian Vault** ที่ทำการแชร์และซิงค์ข้อมูลกับเพื่อน การสร้างไฟล์นอกโฟลเดอร์นี้จะทำให้เพื่อนมองไม่เห็น
- โครงสร้างโฟลเดอร์หลักใน `share_friend/`:
  - `Research/`: สำหรับจัดเก็บเนื้อหางานวิจัยและเอกสารสรุป (เช่น `Research/สรุป/`, `Research/yo_research/`)
  - `Todo/`: สำหรับบอร์ด Kanban (`TO-DO List Research.md`)
  - `Assets/`: รูปภาพและไดอะแกรมที่เกี่ยวข้องกับ Obsidian
  - `Wi-Fi Study Guide.md`: แผนการศึกษา 16 หัวข้อหลัก
